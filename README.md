# SHUT — static demo

This folder contains a static landing / scroll-stop demo for SHUT.

Quick local preview

```bash
# from the `SHUT` folder
npm run start
# then open http://localhost:3000/scroll-stop/
```

Deploy to GitHub + Vercel

1. Initialize git and push to a new GitHub repository. Use the `gh` CLI or the GitHub web UI.
2. Connect the repository to Vercel (recommended via the Vercel dashboard or the `vercel` CLI).

Notes on tokens

- Do NOT paste your Vercel token into random scripts.
- The repository includes a `vercel.json` for static deployment.
